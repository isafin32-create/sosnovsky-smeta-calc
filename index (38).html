Калькулятор предварительной сметы

Чек-лист объекта → автоподбор позиций из прайс-листа → смета с ценой мастера и ценой для клиента.

Данные объекта

Единый чек-лист вместо памяти замерщика — заполняется на первом выезде.

Помещения

Замеры и виды отделки по каждому помещению — модуль сам подберёт позиции сметы.

Помещений пока нет — добавьте первое.

Добавит позиции в смету по выбранным работам. Можно запускать повторно — авто-позиции пересчитаются, строки, добавленные вручную, не тронутся.

Предварительная смета

Жёлтым — себестоимость (цена мастера): видна только вам, в печать и в текстовую выгрузку для клиента не попадает.
